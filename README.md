# OMNI — screenshots

Screenshots for the **OMNI** extension for VS Code
([Marketplace](https://marketplace.visualstudio.com/items?itemName=omnibrig.omnibrig)).
This repository holds pictures only; the extension itself is free to use and is installed from the Marketplace.

Скриншоты расширения **OMNI** для VS Code. Здесь только картинки для страницы расширения.

| File | What it shows |
|---|---|
| `overview.png` | VS Code with the OMNI «Модели» window and the Claude Code chat (the lead) side by side |
| `helper-work.png` | A helper at work: its live steps (web searches in its own engine, pages it opens) and the files it changed, with «Compare» and «Undo» |
| `tasks.png` | «Задачи»: what is running now, each task's stage, cost and buttons |
| `meeting.png` | A meeting of models: round 1, every model thinks on its own, progress per participant |
| `gpt-subscription.png` | GPT through the ChatGPT subscription: the 5-hour and weekly limits, and its work log |
| `resources.png` | «Ресурсы»: balances and subscription limits of every model (amounts hidden), GPU, memory, disk, CPU, today's web searches |
| `programs.png` | Programs started by the models: memory, CPU, pause / stop, paused ones folded |
| `statistics.png` | «Статистика»: how each model does — accepted first time, findings, average time, spend |
